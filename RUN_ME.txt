🚀 TO RUN THE INTERACTIVE APP:

    python todo.py

This will start the NEW interactive mode where you:
1. See "Welcome to the CLI Task App!"
2. Enter Task Name, Description, and Due Date
3. Get automatic confirmation after each field
4. See "✅ Entry completed!" after each task
5. Get asked "Do you want to add another entry? (yes/no):"
6. View all your tasks in a numbered list before exit
7. See "Goodbye! 👋" when done

✅ WHAT THIS APP DOES:

The app guides you step-by-step to create tasks with:
- Task Name
- Description
- Due Date (accepts multiple formats like 2025-12-31 or 12/31/2025)

After each field you enter:
- Automatic confirmation: "[OK] Field name recorded"
- Automatic move to next field
- No commands to remember!

After completing a task:
- Shows "Entry completed!"
- Asks if you want to add another

Before exiting:
- Displays all your tasks in a numbered list
- Shows friendly "Goodbye!" message

═══════════════════════════════════════════════════════════════════════

🎯 KEY FEATURES:

✅ Welcome message
✅ Guided step-by-step input

✅ Automatic field progression
✅ Entry completion confirmation
