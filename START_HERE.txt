3. INDIVIDUAL CLI COMMANDS:

   python todo.py --help           # Show all commands

   python todo.py list             # List tasks
   python todo.py complete 1       # Mark complete
   python todo.py update 1 "New"   # Update task
   python todo.py search "keyword" # Search tasks
   python todo.py delete 1         # Delete task
